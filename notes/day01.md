# 📅 Day 1 – Excel Interface & Fundamentals

## 🎯 Objective

The goal of Day 1 was to become familiar with the Microsoft Excel environment, understand the basic components of the interface, and learn how data is organized within a worksheet.

---

# 📚 Topics Covered

## 1. Workbook vs Worksheet

* **Workbook**: An Excel file that can contain multiple worksheets.
* **Worksheet**: A single spreadsheet within a workbook.

---

## 2. Rows and Columns

* Rows are identified by numbers (1, 2, 3, ...).
* Columns are identified by letters (A, B, C, ...).
* The intersection of a row and column forms a cell.

Example:

| Cell | Meaning          |
| ---- | ---------------- |
| A1   | Column A, Row 1  |
| B5   | Column B, Row 5  |
| D10  | Column D, Row 10 |

---

## 3. Excel Interface Components

### Quick Access Toolbar

Provides shortcuts for commonly used actions such as:

* Save
* Undo
* Redo

### Title Bar

Displays the workbook name and application title.

### Ribbon Tabs

Main tabs available in Excel:

* Home
* Insert
* Draw
* Page Layout
* Formulas
* Data
* Review
* View

### Ribbon

Contains commands organized into groups such as:

* Clipboard
* Font
* Alignment
* Number
* Styles

### Name Box

Displays the currently selected cell reference.

Example:
A1

### Formula Bar

Used to enter or edit data and formulas.

### Worksheet Area

The primary grid where data is entered and managed.

### Sheet Tabs

Used to switch between worksheets within a workbook.

### Status Bar

Displays worksheet status information and calculations.

### Zoom Controls

Used to zoom in and out of the worksheet.
